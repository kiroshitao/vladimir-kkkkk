Вопросы

Частые вопросы

Какая подготовка нужна и нужно ли уметь программировать?

Курс не с полного нуля: нужны базовые навыки работы в сервисах для вайб-кодинга — Claude Code, Codex, Pi Coding Agent, DeepSeek Harness или любой другой. Для подготовки посмотри два видео:

  • Полный гайд по Claude Code ↗
  • Раздел про LLM в гайде по n8n ↗
Сколько времени нужно на курс?

Ориентир — 2–3 часа в день на уроки и домашние задания. Курс можно совмещать с работой, если заранее выделить время на практику. Для результата важно выполнять задания.

Можно ли делать проект для своего бизнеса?

Да. Основной кейс можно адаптировать под свои процессы. Конкретные интеграции и сценарии требуют собственной настройки и проверки. Если своего проекта пока нет, можно учиться на общем учебном проекте.

Будет ли часть про поиск клиентов и работу с заказчиками?

Да. В конце курса разберём поиск клиентов, вводный созвон, выявление задачи, коммерческое предложение, расчёт проекта и договор. Но курс не гарантирует получение клиентов или доход.

Какие дополнительные расходы будут?

Помимо обучения, нужно заложить бюджет на три вещи:

  • Подписку на приложение для вайб-кодинга.
  • Аренду сервера для проекта — ориентир 400–500 ₽ в месяц.
  • API для подключения языковых моделей — стоимость зависит от моделей и объёма запросов.
